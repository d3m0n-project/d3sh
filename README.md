# d3sh

d3m0n os shell utilities.

[![Build & Deploy Docs](https://github.com/d3m0n-project/d3sh/actions/workflows/docs.yml/badge.svg)](https://github.com/d3m0n-project/d3sh/actions/workflows/docs.yml)
[![Build](https://github.com/d3m0n-project/d3sh/actions/workflows/build.yml/badge.svg)](https://github.com/d3m0n-project/d3sh/actions/workflows/build.yml)

## Compilation

To compile, run `make`, this will build these tools onto `./build/`.

## Installation

To install directly these utilities into your d3m0n os filesystem, run

```bash
make export D3M0N_BIN_DIR="./path/to/bin_dir"
```

By default `D3M0N_BIN_DIR=../bin/`
