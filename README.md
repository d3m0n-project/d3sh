# d3sh

d3m0n os shell utilities.

## Compilation

To compile, run `make`, this will build these tools onto `./build/`.

## Installation

To install directly these utilities into your d3m0n os filesystem, run

```bash
make export D3M0N_BIN_DIR="./path/to/bin_dir"
```

By default `D3M0N_BIN_DIR=../bin/`
